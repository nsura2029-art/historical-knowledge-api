## Schema/architecture bindings (must remember)

- `entity_event` has `source_section` NOT `source_url`
- `entity_event.event_type` CHECK has 16 valid values — invalid silently fail `INSERT OR IGNORE`
- `entity_event.date_precision` is DAY/MONTH/YEAR
- `content_section.section_type` CHECK: includes 'overview' but NOT 'history'/'geography'/'demographics' — use 'overview' for all (semantic in heading)
- `content_section.author_type` CHECK: 'human'/'assisted'/'generated' NOT 'auto'
- `entity_relation` uses `subject_entity_id`/`object_entity_id` NOT source/target; no `source_id` or `created_at`
- `slug_redirect.entity_id` NOT `new_entity_id`
- `entity_name.language_code` NOT `lang`
- `entity.slug` is UNIQUE — slug collisions silently fail `INSERT OR IGNORE` AND throw FK violation downstream
- `media_asset.id` FK to `entity.id` (media entities are real `entity` rows with `type='media'`)
- `media_asset.depiction_entity_id` FK to `entity.id`
- `media_rights.source_id` must exist in `source_registry` (use `src_en_wikipedia`, NOT `src_wikimedia_commons`)
- Wikipedia titles are case-sensitive
- Wikipedia REST `plain` endpoint 404s; use `html` + strip tags
- GDELT DOC API rate-limits at IP level (15-30 min cooldown)
- GDELT GKG columns are variable-width — use heuristic for V1Persons
