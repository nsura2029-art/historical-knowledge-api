> **Source of truth for what's in the API.** Every endpoint we ship gets an entry here. New endpoint? Add to this file. Deprecated endpoint? Mark `**DEPRECATED**:` here and keep the entry until the route is removed.

## Live endpoints (28+, as of 2026-08-05)

### Browse & detail

| Method | Path | What it returns |
|---|---|---|
| GET | `/v1/people` | Browse/filter people. Query: `?profession=&country=&generation=&page=&limit=` |
| GET | `/v1/people/{slug}` | Person detail. Slug redirects supported (e.g. `donald-j-trump` → `donald-trump`) |
| GET | `/v1/people/{slug}/timeline` | Chronological life events. Each event has `source` (tier + name + URL) |
| GET | `/v1/people/{slug}/related` | Multi-signal relevance: same profession +0.40, country +0.20, generation +0.10, star_sign +0.05, chinese_zodiac +0.05, era overlap +0.15, shared relation +0.25, popularity +0.05. Max 0.95. |
| GET | `/v1/people/{slug}/references` | Sources grouped by source_registry, sorted by tier A first. Each source has `landing_page` + per-article URL + claims supported. |

## Sort order conventions

- **References**: tier ascending (A first), then by article count descending.
- **Related**: relevance score descending (0.95 max).
- **Timeline**: `start_date` ascending (oldest first).
- **Search**: match score descending.
- **People browse**: `popularity_score` descending (0-100 scale, normalize to 0-1 in calculations).

## Per-route gotchas

- **`/v1/people/{slug}`** — see redirect handling code. 404 → check `slug_redirect` table → follow.
- **`/v1/people/{slug}/related`** — `popularity_score` is 0-100, must normalize to 0-1 in relevance scoring.
- **`/v1/people/{slug}/timeline`** — LEFT JOIN on `source_registry` for tier/name. Use `COALESCE(start_date, '9999-99-99')` in ORDER BY for null-safe sort.
- **`/v1/people/{slug}/references`** — groups by `source_registry.id`. Each source in the response has a `landing_page` (the base URL) AND per-article `external_url`.
- **`/v1/years/{year}`** — uses `substr(start_date, 1, 4) = ?` to filter on year prefix. No date math.
- **`/v1/search`** — 7-tier scoring is case-insensitive, uses `LOWER()` on both sides.
- **`/v1/admin/*`** — auth is currently OPEN. TODO: lock with CF Access or API key before public deploy.

## How to add a new endpoint

1. Add the route file in `apps/api/src/routes/` (or `routes/v1/` if v1-specific).
2. Update the per-endpoint index above.
3. Add a smoke test in the next `v#-smoke.mjs` script.
4. Update `apps/api/AGENTS.md` if a new directory is needed.
