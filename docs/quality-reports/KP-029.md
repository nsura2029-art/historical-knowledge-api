## Unresolved risks

1. **Wikidata full run is rate-limited.** The 20 Trump events are from a test run. The full 494-person Wikidata extraction is blocked by Wikimedia's 403 Too Many Reqs. When the rate limit clears, re-run `wikidata_events_extract.py`. Expected: +30-50 events/person.
2. **DBpedia coverage is date-property-only.** DBpedia has many more properties (career, education, awards) that aren't in our SPARQL query yet. Could add: `dbo:almaMater`, `dbo:award`, `dbo:occupation` with time qualifiers.
3. **Top-500 list gaps.** The curated 500-name list is missing MLK, Steve Jobs, Albert Einstein, Abraham Lincoln, Rosa Parks, Taylor Swift. These are obvious omissions. Future: a "missing famous people" worker to backfill.
4. **Source attribution is FK-only.** The `source_id` field is a string. The UI fetches the source name from `/v1/sources` to render badges. This is 2 HTTP calls per person page. Could be denormalized for performance.
5. **Migration 0032 re-label is a one-time fix.** If any future extraction uses `src_wikidata` for Wikipedia data, the mislabel will re-occur. Consider renaming the column or adding a `source_label` view.
