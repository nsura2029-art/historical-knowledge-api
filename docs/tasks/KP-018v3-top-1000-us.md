## Edge and failure cases

### Edge: slug collision

- Already handled by KP-005's `slug_redirect` + 308 redirect.
- New ingest uses `INSERT OR IGNORE` so collisions are silent no-ops. We log them.

### Edge: entity_event duplicates

- Use `INSERT OR IGNORE` with deterministic IDs. Already proven in KP-029.

### Edge: Wikipedia article not found

- `people_ingest.py` has a skip-existing flag. We extend to skip-missing too.

### Edge: place/org name conflicts with person

- entity table has UNIQUE slug. slug_redirect handles dupes.
